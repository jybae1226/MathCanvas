# MathCanvas 0.3

대학 1·2학년 수학 수업을 위한 오프라인 데스크톱 앱입니다. 설치 후에는 Node.js, 브라우저 서버, GitHub 연결이 필요 없습니다.

## 설치와 실행

빌드 결과는 `release/`에 있습니다.

| 기기               | 파일                                        | 사용법                              |
| ------------------ | ------------------------------------------- | ----------------------------------- |
| Windows x64        | `MathCanvas-0.3.0-windows-x64-setup.exe`    | 실행하여 개인 계정에 설치           |
| Windows x64 휴대용 | `MathCanvas-0.3.0-windows-x64-portable.exe` | 별도 설치 없이 실행                 |
| Apple Silicon Mac  | `MathCanvas-0.3.0-mac-arm64-unsigned.zip`   | 아래 최초 실행 절차가 필요한 시험본 |

Windows 결과물은 실제 패키징된 앱에서 기능 검사를 통과했습니다. 개발자 인증서로 서명하지 않은 개인 시험용 배포본입니다.

Mac ZIP은 공식 Apple Silicon 런타임을 사용한 **서명 전 시험본**입니다. ARM64 실행 파일·실행 권한·프레임워크 링크·앱 코드의 포함 여부를 검사했으며, 실제 Mac에서 실행하거나 Apple 공증을 거치지는 않았습니다. Mac에서 ZIP을 풀고 **Start-MathCanvas.command**를 실행하면 해당 Mac에서 로컬 ad-hoc 서명을 적용·검증한 뒤 앱을 엽니다. 성공 후 MathCanvas.app을 Applications로 옮기세요. 학교의 보안 정책상 실행이 제한되거나 서명 검증에 실패하면, 아래 명령으로 Mac에서 원본을 빌드해야 합니다. 이 과정과 실제 수업 동작은 Mac에서 확인해야 합니다.

## 수업에서 사용하기

1. **함수 · 음함수**를 누르고 오른쪽에 식을 입력합니다. Enter 또는 입력칸 밖을 클릭하면 적용됩니다.
2. **영역 · 교점**에서 두 곡선 또는 좌표축을 선택합니다. 교점은 고정하거나 함수 변경에 연동할 수 있습니다.
3. **교점 찾기 · 구간별 넓이 계산**을 누르면 이웃한 교점 사이를 자동으로 나눕니다. 구간을 체크해 선택 합계를 확인하고 **선택한 구간 색칠 · 값 표시**를 누릅니다. 원·음함수는 아래의 직접 지정 영역을 사용합니다.
4. 일반 함수의 속성에서 접선·미분계수, 정적분, x축과의 넓이를 확인할 수 있습니다.
5. **3D · 회전체**에서 원판법·와셔법, 곡면, 구·원뿔·원환면을 선택합니다. 드래그로 회전합니다.
6. **저장**은 편집 가능한 `.mathcanvas` 수업 파일, **SVG/PNG**는 현재 그림을 저장합니다. 배경을 흰색 또는 투명으로 선택할 수 있습니다. 2D 객체와 3D 수식·구간 설정은 같은 수업 파일에 저장됩니다.

`examples/`의 예제 6개를 **열기**로 불러올 수 있습니다. 와셔법 예제를 연 뒤에는 **3D · 회전체** 탭을 선택하세요. 05·06은 사차함수·삼각함수의 교점별 넓이 예제입니다.

빠른 안내 2쪽과 전체 기능을 담은 22쪽 한국어 설명서는 [사용 설명서 PDF](output/pdf/MathCanvas-0.3-사용설명서.pdf)에 있습니다.

### 교점마다 나누는 넓이

`y=f(x)`와 수직이 아닌 선을 선택하고 탐색 x 범위를 정합니다. 위쪽 함수가 바뀌어도 각 구간의 기하학적 넓이를 양수로 더합니다. 첫 교점 이전과 마지막 교점 이후는 제외합니다. 선택한 구간을 다시 색칠하면 같은 두 곡선의 이전 자동 영역을 교체합니다. 영역은 교점 순서에 연결되며, 교점 개수가 달라지면 다시 분할해야 합니다.

- `x^3-x`와 `0`: 넓이 1/4, 1/4 → 전체 1/2.
- `x^4-5x^2+4`와 `0`: 넓이 22/15, 76/15, 22/15 → 전체 8. 가운데를 제외하면 선택 합계 44/15.
- `sin(x)`와 `0`, 라디안, 탐색 [-7,7]: 네 영역의 넓이는 각각 2 → 전체 8.

자동 분할의 교점 탐색은 x 범위를 사용하므로 y가 화면 밖인 교점도 찾을 수 있습니다. 일반 **교점 표시**는 현재 x/y 화면 범위에서 찾습니다. 모든 근 검출을 보장하지 않으며, 계산 불가 구간이 있으면 전체 합계도 계산 불가로 표시합니다.

자주 쓰는 식:

| 종류            | 입력 예                                                            |
| --------------- | ------------------------------------------------------------------ |
| 다항함수        | `x^3-2x`, `y=x^2`                                                  |
| 삼각함수        | `sin(x)`, `cos(x)`, `tan(x)`                                       |
| 역삼각함수      | `asin(x)`, `acos(x)`, `atan(x)`                                    |
| 지수·로그       | `exp(x)`, `2^x`, `log(x)`, `log10(x)`, `log(x,2)`                  |
| 유리·무리함수   | `1/x`, `sqrt(x)`, `cbrt(x)`                                        |
| 음함수          | `x^2+y^2=4`, `x^2/9+y^2/4=1`, `x=y^2`                              |
| 극좌표          | `r=1+cos(theta)`, `r=cos(3theta)`                                  |
| 회전체          | `sqrt(4-t^2)`, 구간 `[-2,2]` → 반지름 2인 구                       |
| 와셔법          | `f(t)=2`, `g(t)=1`, 구간 `[0,3]` → 부피 `9π` (입력칸에는 `2`, `1`) |
| 3D 곡면         | `sin(x)*cos(y)`, `x^2+y^2`                                         |
| LaTeX 수식 객체 | `\int_0^1 x^2\,dx=\frac13`                                         |

`log`는 자연로그입니다. 삼각함수의 각도 단위는 **화면 → 각도 단위**에서 선택하며, 역삼각함수 출력과 극좌표 각도 구간에도 적용됩니다. `sin^-1(x)` 대신 `asin(x)`를 사용하세요. 일반 역함수 관계는 예를 들어 `x=y^2`처럼 음함수로 그릴 수 있습니다.

## 영역 선택 예

- **원 내부:** A=`x^2+y^2=4`, 방식=A 내부, 조건 `≤0`, x 구간 `[-2,2]`.
- **원과 직선:** A=원, B=`y=0`, 방식=가지 사이, A 위쪽·B 위쪽, 구간 `[-2,2]`.
- **원과 포물선:** A=`x^2+y^2=4`, B=`y=x^2-1`, 방식=교집합, A 조건 `≤0`·B 조건 `≥0`, 구간 `[-2,2]`.
- **두 원이 겹치는 곳:** A=`x^2+y^2=4`, B=`(x-2)^2+y^2=4`, 방식=교집합, 두 조건 `≤0`, 구간 `[0,2]`.

조건은 음함수에서 `(왼쪽 식)-(오른쪽 식)`의 부호를 뜻합니다. `y=f(x)`는 `y-f(x)`로 해석합니다. 음함수의 영역과 넓이는 화면의 y 범위로 제한됩니다. 전체 도형이 보이도록 범위를 설정하세요.

## 단축키와 복구

- Ctrl/⌘+S 저장, Ctrl/⌘+O 열기.
- Ctrl/⌘+Z 실행 취소, Ctrl/⌘+Shift+Z 또는 Ctrl+Y 다시 실행.
- Delete/Backspace 객체 삭제. 입력칸에서는 텍스트 편집에 사용됩니다.
- Esc 작도 취소. 휠 확대·축소, 빈 공간 드래그로 이동. 화면 아래 확대 조절바도 사용할 수 있습니다.
- 작업은 기기에 자동 저장되어 다음 실행 시 복구됩니다. 파일로 저장한 수업은 다른 기기로 옮길 수 있습니다. 휴대용 실행 파일의 자동 복구 자료는 사용자 프로필에 저장되므로, 다른 PC로 이동할 때는 수업 파일을 함께 가져가세요.

## 계산의 범위

수업에서 쓰는 기본 함수와 표준 음함수를 대상으로 한 **수치 시각화 도구**입니다. 임의의 방정식을 정확하게 푸는 기호 연산기는 아닙니다.

- 교점·미분·적분·부피에는 근사 오차가 있습니다. 교점은 현재 화면 범위에서 찾습니다. 아주 가까운 교점, 고주파 함수, 특이점, 격자보다 작은 연결 성분은 놓칠 수 있습니다. 접점도 모든 식에 대해 검출을 보장하지 않습니다.
- 음함수 가지 선택은 위쪽·아래쪽을 지원합니다. 내부 조건은 여러 수직 구간의 합집합을 처리하지만, 격자 해상도보다 얇은 영역이나 수평선에 접하는 중근은 누락될 수 있습니다. 부호 변화가 없는 식 `(x^2+y^2-4)^2=0`은 기본 식 `x^2+y^2=4`로 입력하세요.
- 연동 교점은 생성한 점을 x·y 정렬 순서로 다시 연결합니다. 교점 수가 바뀌면 기존 점이 숨겨지거나 순서가 바뀔 수 있으며 새 교점을 추가하려면 다시 **교점 표시**를 누르세요.
- 정적분은 유한한 구간을 처리합니다. 발산·미정의·수렴 실패 시 값을 표시하지 않습니다. 모든 이상적분을 판별하거나 계산하지 않습니다.
- 와셔법은 x축 또는 y축 위 좌표 `t`에 대한 두 경계를 회전시킵니다. 두 경계가 축 양쪽에 있으면 내부 반지름은 0입니다. 임의의 직선 축이나 음함수 영역 자체를 3D로 회전시키는 기능은 포함하지 않습니다.
- 3D 표면은 유한 격자의 직교 투영입니다. 3D 방정식 `F(x,y,z)=0`을 직접 푸는 기능은 없습니다. 3D 시점은 보기 상태이며 수업 파일에 저장되지 않습니다.
- SVG의 그래프·선·텍스트는 벡터이고, LaTeX 글리프는 고해상도 투명 이미지로 포함됩니다. 다른 PC에서도 글꼴이 유지되지만 수식 부분은 벡터가 아닙니다.

## 개발·빌드

Node.js 24 LTS와 npm을 사용합니다. PowerShell에서 실행 정책 때문에 `npm`이 차단되면 `npm.cmd`로 실행하세요.

```sh
npm ci
npm run dev
npm run lint
npm test
npm run build
npm run test:desktop
npm run dist:win
```

Mac에서:

```sh
npm ci
npm run dist:mac
```

`dist:mac`은 Mac에서 arm64·x64의 DMG·ZIP을 만들고 개인 시험용 ad-hoc 서명을 적용하도록 구성했습니다. Windows에서 서명 전 Apple Silicon ZIP을 만들려면 `npm run dist:mac:zip`을 사용합니다. 이 스크립트는 [Electron의 공식 수동 패키징 방식](https://www.electronjs.org/docs/latest/tutorial/application-distribution)에 따라 공식 런타임에 앱 코드를 넣고 UNIX 권한과 심볼릭 링크를 보존합니다. Mac 최초 실행 스크립트가 함께 들어갑니다. Developer ID 서명·공증이 필요하면 Mac에서 인증서를 연결한 별도 배포 구성이 필요합니다.

`test:desktop`은 별도 임시 프로필과 숨김 창으로 실행하며, 저장 대화상자를 테스트 경로로 대체합니다. 결과와 화면은 `artifacts/`에 저장됩니다. 패키징된 본체는 `npm run test:desktop -- --packaged`로 검사합니다. 다른 실행 파일은 환경 변수 `MATHCANVAS_EXECUTABLE`로 지정할 수 있습니다.

세 배포 파일을 만든 뒤 `node scripts/verify-releases.mjs`로 실행 파일 형식, 앱 코드 버전, Mac 헬퍼와 링크, Windows 패키징 앱 검사 결과를 확인합니다. SHA-256과 검사 요약은 `release/checksums.json`에 기록됩니다. 설치 프로그램을 통한 설치 과정이나 실제 Mac 실행까지 자동 검증하는 명령은 아닙니다.

설명서 원본은 `scripts/create-manual.py`입니다. Windows의 맑은 고딕을 PDF에 포함하며, ReportLab·pypdf·PyMuPDF가 필요합니다. 예제는 `node scripts/create-examples.mjs`로 다시 생성할 수 있습니다.

상세 분석과 설계 판단은 [ANALYSIS.md](ANALYSIS.md)를 참고하세요.
